# Frost Leaves（霜叶）

一个**自托管的私人文件存储**小工具：文件只存在你自己的电脑里，手机 / 其他电脑通过局域网或点对点私有组网访问，支持分享链接与二维码。

> Self-hosted private file storage. Your files stay on your own computer.

## 功能特性

- 🖥 **Windows 服务端**：独立可执行文件，桌面端只做管理（关掉管理窗口服务照常运行）
- 📱 **Android 客户端**：浏览、上传、下载、多选批量操作
- 🔗 **分享链接**：可为单个文件/目录/多选文件生成访客链接，支持有效期、下载次数限制、只读/投递箱权限
- 📷 **二维码**：分享弹窗内直接出二维码，手机相机扫码即开
- 🔒 **HTTPS(TLS) 加密**：内置自签名 CA，服务端可一键把 CA 装进本机受信任根证书
- 🌐 **公网访问（可选）**：调用你本机已安装的第三方点对点私有组网客户端，生成公网地址给亲友访问
- 🧑🔧 **管理通道鉴权**：管理接口仅回环或凭管理令牌访问
- 🌏 **中英双语界面**：跟随系统/设置切换

## 系统要求

| 端 | 要求 |
| --- | --- |
| Windows 服务端 | **x64 架构**，Windows 10 1809（Build 17763）及以上；建议 Win10 21H2 / Win11 |
| Android 客户端 | **Android 5.0 (API 21)** 及以上；建议 Android 8.0+（5.0~7.x 为实验性兼容，存在 TLS/文件读写兼容问题与安全隐患，不建议日常使用） |

## 目录结构

```
cmd/server/         Go 服务端（HTTP/HTTPS 网关、分享、二维码、TLS、公网隧道）
pkg/file_gateway/   文件网关：鉴权、配额、审计、分享
pkg/security/       密钥、签名、设备令牌
flutter_app/        Flutter 客户端 + 桌面管理端（Windows / Android）
docs/               架构与构建说明
```

## 从源码构建

### 服务端（Go）
```bash
go build ./cmd/server
```

### 客户端（Flutter）
```bash
cd flutter_app
flutter pub get
flutter build windows --release   # Windows 桌面端 / 管理端
flutter build apk --release       # Android 客户端
```

构建环境参考：Flutter 3.24.5 stable、Go 1.26.x、Android compileSdk 34 / minSdk 21。

## 快速开始

1. 双击 `FrostLeaves_Server.exe` 启动服务端（首次会自动生成 CA 与密钥，存放在程序目录 `data/`）
2. 打开桌面端 →「系统配置」设置存储目录、端口，保存后重启服务端
3. 「分享管理」里可生成分享链接与二维码；需要 HTTPS 时在「系统配置」一键安装证书
4. 手机装 APK，连到服务端的局域网地址（首次需要服务端审批设备）

## 关于第三方组网客户端

本项目**不内置、不打包、不自动下载**任何组网客户端。公网访问功能只调用你本机已安装的第三方客户端命令行；
该客户端有它自己的许可协议与商标，请自行前往其官网获取并在其后台完成登录/开启公网访问。
相关配置项：系统配置 →「组网命令」（填客户端可执行文件名称或绝对路径）。

## 隐私与安全

- 所有文件保存在你自己指定的存储目录，本项目不上传、不收集任何文件内容
- 仓库内**不包含**任何证书与私钥：CA/服务器证书/设备令牌都在首次运行时由服务端本地生成
- 自签名证书浏览器会提示「不安全」，属正常现象，流量仍然是加密的
- 发现安全问题请按 [SECURITY.md](SECURITY.md) 反馈
